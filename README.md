Hope Foundation - NGO Management System

A web-based management portal designed for the Hope Foundation to streamline volunteer management, project assignments, attendance tracking, and social impact analytics.

📌 Features

Volunteer Directory: Onboard, search, and manage volunteer records, skills, locations, and availability.

Project Assignments: Assign volunteers to ongoing social welfare projects with specified roles and schedules.

Attendance Logging: Track volunteer service hours and record field attendance status (Present, Late, Absent).

Impact Analytics: Measure key impact metrics including total service hours, beneficiaries reached, and economic value created (in INR).

RESTful API: Clean backend architecture powered by Python and Flask.

 Getting Started

Follow these steps to set up and run the project locally on your machine.

Prerequisites

Ensure you have Python 3.8 or higher installed on your system.

1. Installation

Clone the repository and install the required dependencies:

git clone https://github.com/YOUR_USERNAME/NGOmanagementsystem.git
cd NGOmanagementsystem
pip install -r requirements.txt


2. Run the Server

Start the Flask backend application:

python server.py


3. Access the Web Application

Open your browser and navigate to:

http://localhost:5000
